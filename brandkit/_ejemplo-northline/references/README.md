# Referencias de motion

Poné acá de 3 a 5 referencias de piezas cuyo movimiento te guste: capturas (`.png` / `.jpg`), clips cortos (`.mp4`) o un `links.txt` con URLs. Pueden ser de tu marca o de otras.

En la sección 9 de `BRANDKIT.md`, anotá para cada una **qué tomar** ("cómo entra el texto", "el ritmo de cortes", "el uso de un solo color") y **qué no** ("la paleta", "las partículas").

Las referencias sirven para decidir el look y el motion. No se copian: Claude las usa para traducir tu gusto a números (duraciones, curvas, alineación) y el director de arte lo aprueba sobre frames reales.

No pongas material confidencial de clientes acá, salvo que el repo sea privado y el cliente lo autorice.
